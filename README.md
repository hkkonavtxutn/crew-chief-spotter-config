## Overview

Crew Chief Spotter Config provides a clean GUI for configuring the Crew Chief racing co-driver application's voice personality, gap call frequency, incident reporting sensitivity, fuel calculation behavior, and custom button bindings — making Crew Chief's extensive configuration accessible without editing raw property files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Crew Chief Spotter Config** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Personality Settings** | Configure the spotter's voice callout frequency and content |
| **Gap Calls** | Set interval and distance threshold for position gap announcements |
| **Fuel Calculator** | Configure lap count method and fuel reserve percentage for calls |
| **Button Bindings** | Assign hardware buttons for spotter acknowledgement and queries |
